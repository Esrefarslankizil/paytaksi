# PayTaksi - Elazığ 3D Taksi Çağırma Uygulaması 🚖

Modern, Three.js ve React destekli interaktif 3D haritalı taksi çağırma ve tarife platformu.

## Özellikler

- **3D İnteraktif Harita:** Three.js ile modellenmiş izometrik şehir dokusu, binalar, yollar ve animasyonlu taksi güzergahları.
- **Glassmorphic Tasarım:** Buzlu cam efektli modern modal kartlar ve kullanıcı dostu arayüz.
- **Dinamik Rota:** Seçilen güzergaha göre 3D parabolik kavisli rota animasyonu.
- **Mobil Uyumlu (Responsive):** Hem masaüstü hem de mobil cihazlar için optimize edilmiş kamera açıları ve dokunmatik kontroller.
- **Elazığ Popüler Noktaları:** Park Yirmiüç, Elysium AVM, Fırat Üniversitesi, Otogar, Havalimanı vb. entegre noktalar.

## Kurulum ve Çalıştırma

1. Bağımlılıkları yükleyin:
```bash
npm install
```

2. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

3. Canlı derleme (build) alın:
```bash
npm run build
```
